# homebrew-ofd

Homebrew tap for **[OFD预览](https://github.com/ChengRui24/OFD-preview-Mac)** (OFD Preview for macOS).

## Install

```bash
brew tap ChengRui24/ofd
brew install --cask ofd-preview
```

Upgrade later:

```bash
brew upgrade --cask ofd-preview
```

Uninstall:

```bash
brew uninstall --cask ofd-preview
```

## Requirements

- Apple Silicon (arm64) Mac  
- macOS Big Sur or newer  

## Source app

Built from [ChengRui24/OFD-preview-Mac](https://github.com/ChengRui24/OFD-preview-Mac), based on [OFDRW](https://github.com/ofdrw/ofdrw) (Apache-2.0).
